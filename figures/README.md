# Manuscript figures

Run:

```bash
python -m pip install -r requirements.txt
python scripts/make_figures.py
```

The script generates the two figures used in the manuscript:

1. `Figure_1_Exact_Equivalence_Class` — Ballard Mark V fixed-temperature equivalence geometry.
2. `Figure_2_Normalized_Singular_Spectra` — 250 W column-normalized Jacobian singular spectra for progressively richer experimental designs.

Both PNG (300 dpi) and vector PDF outputs are generated locally in this folder.
